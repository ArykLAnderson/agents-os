# Explicit agent specification disposition

## Policy

Pi does not install Agent OS explicit agent specifications. Pi workflow agents use task-defined prompts with independently selected model, thinking, and tools. Durable specialist doctrine belongs in skills or exact mandates.

OpenCode may retain explicitly installed agents where its static harness requires them; Pi's dynamic workflow policy does not imply cross-harness parity.

## Operational quarantine

The former Pi workflow roles, disabled regeneration script, and old Pi subagent copies are retained reversibly under:

`~/.pi/agent/pi-extensible-workflows/quarantine/2026-07-26-explicit-role-bindings/`

They are outside active role and agent discovery.

## Follow-up deletion gate

Delete a canonical agent specification only after:

1. every active harness consumer is identified;
2. unique doctrine is moved to a skill or intentionally retired;
3. source references no longer dispatch by that agent name;
4. adapter sync and doctor pass without it.
