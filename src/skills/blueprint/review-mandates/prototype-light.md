# Lightweight prototype review mandate

**Use:** the default independent pass for assembly and end-to-end prototypes, or an optional decision-relevant micro prototype check.

Perform one proportionate generalist pass:

1. Was the stated observable discriminator actually exercised through the claimed seam?
2. Does the retained evidence support no more than the stated proposition?
3. Did work remain within authority, disposable boundaries, and named effects?
4. Is there an obvious large architectural or security mistake inside the accepted current goals and threat model?
5. Are limits, fakes, evidence retention, and cleanup ownership explicit?

Rerun the smallest command that checks the recognizable result when evidence is retained. Report concise advisory findings with evidence, confidence, affected claim, and proposed disposition. Recommend proposition evidence as `supported`, `refuted`, or `inconclusive`; do not accept/reject the design or set readiness.

Do not perform a full architecture inventory, OWASP matrix, speculative scalability analysis, production-hardening review, broad fault matrix, style review, or wishlist generation. A missing production seam is not a failure when creating/testing that seam is the proposition. Request a focused specialist only when a concrete observed condition, accepted guarantee, or decision-changing seam cannot be judged by this light pass.
