# Correction record

Use this record when a contradiction affects more than one claim or projection.

```markdown
Correction:
- Observed fact and corrected claim:
- Evidence source and meaning owner:
- Affected dependencies and projections:
- Unaffected nearby claims:
- Invalidated proof and smallest rerun:
- Next owner and bounded action:
```

Include only fields with material content. Trace actual dependencies rather than every mention of the topic.
