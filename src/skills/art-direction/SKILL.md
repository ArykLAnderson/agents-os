# Art Direction

Art Direction is an optional lens used by Presentation. It sharpens visual intent and useful variation; it is not an independent workflow, semantic authority, or implementation owner.

## Shape the lens

Start from the Presentation task, audience, medium, and constraints. Infer a compact brief or accept one supplied by the user. Set explicit dials when they help comparison:

- **Variance:** familiar and restrained ↔ distinctive and surprising;
- **Motion:** still and quiet ↔ expressive and transitional;
- **Density:** spacious and sparse ↔ layered and information-rich.

The dials describe a range, not a scorecard or fixed aesthetic ban. Keep the chosen point of view legible in composition, typography, imagery, motion, and rhythm, while preserving the user's task and the medium's limits.

## Use references

Use a small set of references and anti-references when they clarify intent. For each, name what to borrow or avoid—such as pacing, contrast, framing, material feeling, or information density—not a framework, library, brand, or copied surface. An anti-reference is a warning about a failure mode, not a universal prohibition.

## Hand back to Presentation

Return one concise lens: visual intent, selected dial positions, references and anti-references with reasons, deliberate exclusions, and questions for rendered inspection. Presentation decides how to realize it and whether it serves the surface. Motion must yield to reduced-motion needs; density must yield to comprehension and accessibility; visual distinctiveness must not obscure source meaning.

Art Direction cannot write or rewrite copy, change claims, select semantic hierarchy, invent diagram meaning, approve publication, or own the implementation. If the lens creates meaning-changing pressure, stop and return the question to Presentation and the relevant source authority.
