## Current Direction

For a website, Document should sharpen and govern content: writing, reader
journey, evidence-backed meaning, and structural or technical writing
presentation. A dedicated frontend workflow, with Impeccable as the leading
candidate, should own the rendered interactive and visual surface.

The active Frame exists to define the shared boundary where content structure,
visual hierarchy, accessibility, acceptance, and publication affect both
owners.
