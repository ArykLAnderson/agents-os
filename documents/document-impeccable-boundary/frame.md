# Separate website content authority from visual-surface fidelity

## Outcome

A website can be developed through portable Agent OS skills with Document
sharpening and governing its content while a dedicated frontend workflow owns
the rendered interactive and visual surface, without either workflow silently
changing the other's authority.

## Active Discovery

### Define the Document and Impeccable fidelity boundary

- Discovery ID: `discovery:30ad8a7e-f6e6-44ab-89bf-03d4a0d1d431`
- Category: `frontier`
- Human authority: `unclear`

Immediate consumer: a user or agent creating a website from governed content.

Human direction on 2026-08-05: Document should own writing, reader journey,
evidence-backed meaning, and structural or technical writing presentation;
Impeccable is the leading candidate to own the rendered interactive and visual
surface.

Current Document terrain also claims target representations, HTML
responsiveness and accessibility, visual semantics, rendered inspection,
publication state, and completion across representations, creating overlap.

Boundary-changing questions remain:

- What is the canonical content handoff?
- Which hierarchy, emphasis, diagrams, accessibility text, and structure remain
  semantic?
- How does visual iteration return meaning-changing pressure without silently
  editing content?
- What accessibility guarantees are shared across the boundary?
- How do website acceptance and publication work across two governed artifacts?

Exclusions:

- Taste Skill integration
- Internal adapters, files, or commands
- Wholesale adoption of Impeccable machinery
